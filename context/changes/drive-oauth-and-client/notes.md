# Google OAuth Setup (one-time, manual)

Required before the first sign-in works — both locally and on Render.

## 1. Create or select a Google Cloud project

Go to [Google Cloud Console](https://console.cloud.google.com/) and create a new project (e.g., "Bookshelf") or reuse an existing one.

## 2. Enable the Google Drive API

APIs & Services → Library → search "Google Drive API" → Enable.

## 3. Configure OAuth consent screen

APIs & Services → OAuth consent screen:

- **User type**: External
- **Publishing status**: Testing (keeps it from requiring Google verification)
- **App name**: Bookshelf
- **Support email**: your Gmail
- **Scopes**: add only:
  - `https://www.googleapis.com/auth/drive.file`
  - `openid`
  - `email`
  - `profile`
- **Test users**: add your Gmail address — sign-in will be rejected for anyone not on this list while the app is in Testing mode.

## 4. Create an OAuth 2.0 Client ID

APIs & Services → Credentials → Create Credentials → OAuth client ID:

- **Application type**: Web application
- **Name**: Bookshelf Web
- **Authorized redirect URIs**:
  - `http://localhost:3000/api/auth/callback/google` (local dev)
  - `https://<your-service>.onrender.com/api/auth/callback/google` (production)

Copy the **Client ID** and **Client Secret**.

## 5. Wire into Render

In the Render dashboard for `bookshelf-web`, set the `sync: false` env vars:

| Key | Value |
|-----|-------|
| `GOOGLE_CLIENT_ID` | from step 4 |
| `GOOGLE_CLIENT_SECRET` | from step 4 |
| `BOOKSHELF_ALLOWED_EMAIL` | your Gmail address |
| `AUTH_URL` | `https://<your-service>.onrender.com` |

`AUTH_SECRET` and `AUTH_TOKENS_ENCRYPTION_KEY` are auto-generated by Render (`generateValue: true` in `render.yaml`) — no manual action needed.

## 6. Local dev

Copy `.env.example` to `.env.local` and fill in:
- `DATABASE_URL` — your local Postgres or the Render external connection string
- `AUTH_SECRET` — `openssl rand -base64 32`
- `AUTH_TOKENS_ENCRYPTION_KEY` — `openssl rand -base64 32` (different value)
- `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` — from step 4
- `BOOKSHELF_ALLOWED_EMAIL` — your Gmail

## Notes

- The "Unverified app" warning on Google's consent screen is expected for a Testing-mode app on `*.onrender.com`. Click "Advanced → proceed" to continue — this is acceptable for solo use.
- The app stays in Testing mode indefinitely; Google verification and the annual security assessment are post-MVP polish.
- Render free-tier web services spin down after 15 min idle (30–60s cold start). The OAuth redirect could land on a cold instance — harmless but slow. Upgrade to Starter plan ($7/mo) to eliminate cold starts when this becomes annoying.
